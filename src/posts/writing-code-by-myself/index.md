---
title: Writing code by myself
date: 2026-10-28T17:26:35+07:00
---

I like writing code by myself. I say it with pride.

I don't want to use AI-generated code, even when it sometimes suggest decent-looking code.

Because "sometimes" is not convincing enough, and the risk is too high.

I want to experience the struggle of finding solution to a problem.

I want to feel like giving up because of not getting anywhere.

I want to feel the joy of finding out the solution. The joy of crafting high-quality work. The joy of understanding.

The progress is the point.

I then can explain how things work. Explain where the problem lies. Explain how to solve it.

I may end up being slower because of it. I may end up being looked down upon as scared and don't want to change.

But, I'm willing to walk on this path.

Because it's the right path for me to go.

Because software engineering is not only about writing code.

Because I care.
